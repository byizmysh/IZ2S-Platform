# Contributing

Build from a clean checkout using BUILDING.md. Keep vendor source pinned and record adapter changes in generated mirrors. Add meaningful regression tests for behavioral changes. Keep PC-host support separate from console ABI support, and never label an emulated/model check as a physical-console pass.

Do not commit BIOS/game dumps, personal saves, credentials, local device addresses, logs or crash dumps. Native changes need updated matching assets, hashes and qualification notes. Packaging tools must stay local unless a maintainer explicitly chooses to publish.
