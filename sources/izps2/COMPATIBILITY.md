# Compatibility

| Area | Tested or required |
| --- | --- |
| Platform | Nintendo Switch 2 with IZ2S RUN25 and native ABI 7 |
| Storage | Filesystem access is required for importing and managing SD files |
| Game library | A user-supplied 4 MiB PS2 BIOS and ISO or CHD game images |
| Need for Speed Underground 2 | NTSC SLUS-21065 used for the local ARM64 podium replay and shutdown check |
| Grand Theft Auto San Andreas | PAL SLES-52541 used as the earlier local regression control |
