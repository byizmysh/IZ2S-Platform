# Changelog

## 0.5.0

- Includes all runtime resources in one IZA download for installation through IZ2S.

## 0.5

- Packages the R1322 engine under the display name **IZPS2 emulator**.
- Joins screenshot workers on shutdown and runs the hosted graphics driver report inline.
- Verifies IZA import and fresh-install SD archive readback offline.

## R1249 test build

- Collects costly EE JIT intervals on the verified GTA SA PAL checkpoint. A matching replay can warm the selected blocks in their original order.
- Rejects blocks that overlap earlier physical ranges. The profile stores addresses, lengths and checksums and validates guest bytes before compiling them.
- Keeps the existing hosted JIT domains and the built-in checkpoint prefix. The late profile is enabled by `ee-checkpoint-learn-late.flag` in the IZPS2 module directory.
- Packages the tested R1249 engine and frontend under the display name **IZPS2 emulator**. The engine and native frontend code are byte-identical to the candidate.
