# IZPS2 внутри пакета .iza в RUN25

Проверка выполнена локально и на Switch 2 с GTA San Andreas PAL, SLES-52541, CRC B440A8FE, с контрольной точкой `izps2-r799-gta-sa-entry.p2s`. Во всех аппаратных журналах ниже включены JIT EE, IOP, VU0 и VU1. Fastmem и MTVU выключены.

| Участок | Что подтверждено | Что исправлено или осталось проверить |
| --- | --- | --- |
| Пакет и загрузка кода | R1133 завершалась с `0xe606` при раздельном размещении сегментов. После снижения требований к расстоянию между RX и RW загрузчик дошёл до вызова движка. | R1146 локально прошла сверку 39 964 релокаций на расстояниях ±32, +128 и −64 ГиБ. |
| BIOS, ISO, ресурсы GS | Старые пути не совпадали с путями SDK. Ранее отдельно отказали создание папок, поиск BIOS и загрузка графических ресурсов. | R1146 на Switch 2 открыла BIOS, тот же ISO, Vulkan и восстановила снимок. |
| Прогрев EE | R1143 считала 65 616 байт со статусом `ok`, сверила 1 040 записей и подготовила 1 024 блока за 101,050 мс. R1144 и R1146 дошли до первого гостевого vblank с пустой начальной записью диспетчера, прежде чем началось чтение профиля. | Путь чтения работоспособен. В обоих прогонах с отложенным прогревом дальнейшее выполнение не подтверждено. В R1146 отметка первого vblank содержит 0 принятых отправок изображения. |
| Запись профиля EE и кэшей GS | Открытие временного файла шло через VFS, переименование, удаление и обход каталога для пути `sdmc:/…/cache` шли через libc. | В R1145/R1146 операции направлены через SDK. Локальная проверка покрыла ошибку публикации с сохранением старого файла, успешную подмену, повторное открытие, перечисление и удаление временного файла. Запись профиля при штатном выходе на Switch 2 ещё не наблюдалась. |
| Настройки BIOS | R1144 получила `errno 88` при чтении NVRAM и MEC. Открытие без учёта регистра обходило VFS, рядом с BIOS запись запрещена. | R1146 сохраняет служебные файлы в `saves/armsx2/firmware` и читает прежнюю копию рядом с BIOS при отсутствии новой. Проверено локально. Ошибок NVRAM/MEC в журнале R1146 нет. |
| Карты памяти и сохранения | R1144 открыла карту и прочитала контрольную точку, но запись резервного ZIP отказала из-за использования пути через libc. | R1146 публикует ZIP через SDK и зафиксировала `MemcardBackup: backed up Mcd001.ps2` на Switch 2. Обычный Save State и Save and Exit требуют прогона из игры. |
| Диагностические флаги | Часть опций читается из файлов `*.flag` в корне модуля. Этот каталог отсутствует среди маршрутов `HostVFS::stat` для таких путей. | Старые тесты, переключаемые файлами, требуют отдельной проверки. Их параметры нельзя восстанавливать по умолчанию из старых файлов на SD. |
| Потоки и логи | SDK разрешает дочерним потокам с областью `SB4_STORAGE_HOSTED_READ_SCOPE` только чтение. Прошлый `runtime-latest.log` может оставаться на SD после запуска в новом контейнере. | Свежие источники диагностики — `emulog.txt` и журнал работника соответствующей версии. Долговечность кэшей, создаваемых потоками GS, и повторное открытие той же сессии аппаратно не подтверждены. |

Метки R1146 в названии плитки, журнале работника и игровых OSD относятся к одной сборке. Строка `IZPS2_BUILD` в её emulog сохранила старый идентификатор R1144. В контрольном R1147 изменены обе константы маркировки.

Сопоставимых игровых окон для оценки FPS ещё нет. Прирост производительности не измерен.
