First-time setupPrepare your ARM input deviceARM INPUT
  1. 1 · Prepare

    Linux, Python 3, systemd, root SSH and a USB device/OTG controller. Connect LAN before installation.

  2. 2 · Install

    Install the keyboard + controller package over SSH, or download it for manual installation.

  3. 3 · Connect

    Connect the USB data/OTG port to Switch. Check that keyboard + controller are ready; no manual A is needed.

First connect from a terminal and verify the board’s host fingerprint. Use ssh-copy-id USER@ARM_IP to authorize an existing key. Passwords stay in your terminal; private keys stay on this PC.

Download the complete ARM package below, or copy packages/iz2s-arm-input.tar.gz from the platform folder. Enter SSH passwords in your terminal.

scp packages/iz2s-arm-input.tar.gz root@ARM_IP:/tmp/
ssh root@ARM_IP

On ARM:

mkdir -p /tmp/iz2s-input-setup
tar -xzf /tmp/iz2s-arm-input.tar.gz -C /tmp/iz2s-input-setup
cd /tmp/iz2s-input-setup/arm-input
sudo python3 install.py --folder /opt/iz2s/arm-input

Use your actual SSH account. Non-root accounts need sudo for manual installation. The bundled README includes prerequisites, troubleshooting, offline copying and removal.
