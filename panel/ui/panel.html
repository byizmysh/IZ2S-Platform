What happens during connection?
PC Wi-Fi switches to a direct connection with the console to send the initial loader. IZ2S Platform then restores your Wi-Fi network and checks the console IP. This can take a few minutes; progress appears above.

   

  

  
Confirm the fresh lobby and click Connect and install save. The panel restores Wi-Fi, verifies the console connection and automatically installs IZ2SCIV.Civ7Save. Keep Awaiting payload open until completion.

CIVILIZATION VII · IZ2S
Questions and answers
Ten answers for setup, launch and connection.
What do I need for the first installation?
For first setup, you need a console with firmware 23.0.1, an SD card, a Civilization VII 1.0.0 cartridge for Nintendo Switch 1, your prod.keys and a Linux PC with NetworkManager and a Wi-Fi adapter. The PC setup step checks the keys, components and network permissions. This edition is available only for native Linux; Windows and WSL are not supported.
Which languages should I select on the console?
Choose English for the console interface and English (US) for the USB keyboard before opening Civilization VII. Paths to these two settings use the panel language. Game menus and the save cleanup path stay in English.
Where should I extract the SD archive?
In the extracted IZ2S-0.34-linux folder, find iz2sciv-core-sd.zip next to install.sh. Extract that SD archive to the card root so SD:/iz2s/ is directly on the card. Merge folders and replace matching files. Keep Nintendo and your other files. The kit includes IZ2S Cheese, IZPSX, Foldrift and NX2 BreRUN.
Do I install the save manually after connecting?
No. Connect and install save restores PC Wi-Fi, verifies the console loader and automatically installs IZ2SCIV.Civ7Save. Keep Awaiting payload open until completion. The installation button is available when an interrupted transfer needs to be resumed.
What if the console IP is not found?
Open Awaiting payload on the console. Expand Console IP below Session status, search again or enter the IP shown on the console. A suggested address is only a candidate: the panel verifies the loader before sending data.
What should I do after a black screen or an error?
A black screen can appear instead of IZ2S CORE IS RUNNING. Wait one minute, then close Civilization VII and launch a Switch 2 game while holding R, without restarting the console. On FAILED at stage, filesystem access unavailable or a freeze, fully restart the console and retry Load Game. After more than 7 unsuccessful attempts, start the full procedure again.
When should I repeat the full procedure?
Reuse your current save if it is compatible with the update. Repeat the full procedure when the save needs replacing, when switching from another loader, or after more than 7 unsuccessful launches. At step 3, clear all Civilization VII save data for the selected profile before continuing.
How do I configure PC Link or FTP?
For PC Link, open Launch, choose Configure PC Link, enter the console IPv4 address and click Start PC Link. Save pc-link.cfg in the iz2s folder on the SD card, reopen IZ2S, then press R + L3. Keep the PC and console on the same local network. For FTP, press L + R3 on the console and click Connect FTP in the panel.
Do I need to install everything after restarting the console?
The installed save remains, but IZ2S does not stay running after a console restart. Use the Launch instructions: open Civilization VII, choose Load Game, check the result, then launch a Switch 2 game while holding R. Repeat the R-held launch once if needed.
Will my ordinary game saves be deleted?
Automatic installation replaces only IZ2SCIV.Civ7Save. If you repeat the full procedure, clear all Civilization VII save data for the selected profile in System Settings at step 3.
