  2. 2 · Install

SSH setup

First connect from a terminal and verify the board’s host fingerprint. Use ssh-copy-id USER@ARM_IP to authorize an existing key. Passwords stay in your terminal; private keys stay on this PC.

Download the installer below and copy it to your ARM device. Run on ARM:

sudo python3 iz2s-arm-input.run

Use your actual SSH account. Non-root accounts need sudo. The installer includes keyboard + controller and works offline.
