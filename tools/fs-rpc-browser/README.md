# Super File Bros. in IZ2S Platform 0.22

Super File Bros. is the integrated browser file manager behind **Files & uploads → Open file manager**. The entry appears after console connection. It browses console storage and installed-game exports, displays connection and transfer state, and provides SD uploads, folder navigation and optional FTP access for an external client.

The file list scrolls inside its workspace; toolbars and navigation remain available. FTP is optional for an external file manager. The browser view and IZPSX Games and BIOS share the file-service entry point, subject to the console's current native-resource ownership.

Use the correct writable SD location before uploading. Check file names, available space and game/application ownership. Follow checkpoint verification to resume an interrupted upload using the same original file. Cancel an unfinished transfer before starting an incompatible replacement. Deletion is explicit and may be permanent; back up needed files first.

This tool is included in the platform's Linux candidate source. Native console features remain gated by the platform/component host declarations; merely opening a web page is not end-to-end qualification. The standalone upstream project remains https://github.com/byizmysh/super-file-bros.
