# Support and useful diagnostics

For IZ2S panel 0.3.2 / launcher 0.32, Civilization VII edition.

Describe the PC operating system and architecture, console firmware, exact cartridge edition/game version, panel version, launcher revision, and the step that fails. Say whether this is a first install, update or normal launch; include the exact visible error and whether it repeats after reboot.

Export the current session log from the panel. For startup delays, report the stage (before menu, first render, or loading an application) and whether a repeat launch behaves differently. For SD verification failures, include the package name and expected/actual file sizes and SHA-256, not only the visible RUN label. For connection failures, distinguish Awaiting payload, PC Link and the FTP client/server states.

Before sharing, remove local authorization URLs/fragments, access tokens, pairing secrets, usernames, private paths and addresses you do not want to disclose. Never send `prod.keys`, `title.keys`, game images, BIOS or personal saves. The `data/` directory is private runtime state, not a diagnostic bundle for publication.

See [FAQ](FAQ.md), [installation](docs/INSTALLATION.md), [compatibility](COMPATIBILITY.md) and [source scope](SOURCES.md). A verified archive or FTP transfer does not establish that a console boot succeeded.
