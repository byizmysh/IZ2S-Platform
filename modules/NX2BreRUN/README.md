# NX2 BreRUN 0.7.0

Switch 2 game loader distributed as an independent full-screen NRO.

[Source and instructions](https://github.com/byizmysh/nx2-brerun) - [Included release](https://github.com/byizmysh/nx2-brerun/releases/tag/v0.7.0)

The IZ2S SD kit uses `iz2s/modules/nx2-brerun/launcher.nro`. Keep existing game data and settings folders beside it when replacing the program.
