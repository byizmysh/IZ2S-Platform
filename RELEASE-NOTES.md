# IZ2S 0.34

- Updated the Linux PC panel and console launcher to 0.34.
- The launcher draws the menu before automatic import begins. Paging reuses the NRO catalog. Successful FTP changes to app files refresh the catalog.
- Added NX2 BreRUN 0.6.0 to the SD package and PC application library. It opens full screen and stays in its own module directory.
- IZA Split and Float, PC Link and FTP carry over from RUN33 v26. IZPS2 is available as a separate PC library export with its SD defaults.

The fixed boot files and SD-flex policy match RUN33 v26. An existing matching save can be reused. The SD archive supplies the matching launcher, IZ2S Cheese, IZPSX, Foldrift and NX2 BreRUN. `IZ2S-0.34-linux.zip` includes the PC installer and `iz2sciv-core-sd.zip`. The panel also offers the SD ZIP as an individual download.

The local release is checked on a PC. A fresh console Load Game and launching NX2 BreRUN from IZ2S require console verification.
