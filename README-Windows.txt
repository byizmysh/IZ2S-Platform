IZ2S Platform 0.3.0 — Windows x64

1. Extract the entire ZIP into a new folder.
2. Double-click Start.cmd (Install.cmd is an alias).
3. Let first-run setup finish; missing dependencies download automatically.
4. Keep this folder. Later, use Start.vbs or Start.cmd. Existing dependencies are reused.

Node.js is bundled. Setup prepares private Python and Pillow and an SSH client if missing. An Internet connection is needed for downloads.
SmileBASIC 4 is supported. Civilization VII is Linux Only, as marked in the panel. BlitBun and VacooTube PC media hosts require Linux.
Prepare Cardputer ADV or Switch 1 in Device setup. Pairing is automatic; no manually obtained keys are required. A device prepared on another PC may need to be paired again.

A Windows Firewall dialog for Node.js is a network permission prompt, not a Node.js installer. Allow private-network access when connecting a console.
