# IZ2S RUN34 0.34

Use the original IZtwiNS2 and IZPSX application files. Both can occupy either pane. Compatible Vulkan-only apps with private control buffers are also selectable.

- Press R + Up in the launcher. The Split row under the cards shows the next step. Choose each app card with A. The pair opens after the second selection. Press B or R + Up again to cancel before the pair opens.
- Press Plus and Minus together to open the Full HD window controls. Repeat the chord or press B to hide the controls and window frames.
- Use Left/Right and A, or tap a control. X switches focus and Y cycles audio while the controls are open.
- Tap a pane to focus it. The light blue frame marks the active pane. The first tap on an inactive pane selects it.
- Swap changes sides in Split and exchanges foreground and background in Float.
- In Float, drag the floating title bar to an edge or choose Corner. Smaller/Larger selects one of five sizes, about 1/8 to 1/4 of screen area.

With controls open, the blue frame shows focus and the speaker icon shows audio. Tap a speaker to toggle that app's sound.

NRO apps use a full-screen handoff and cannot join this split session. The NRO Split compatibility runtime has been removed.

When an app exits normally, the other remains open. The launch save must use the matching boot core. Install the SD-flex save once to allow future compatible SD updates. Console execution is unverified.
