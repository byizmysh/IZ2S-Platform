# nanosvg

`nanosvg.h` (SVG parser) and `nanosvgrast.h` (rasterizer) by Mikko Mononen,
<https://github.com/memononen/nanosvg>, under the zlib licence in each
file's header. Copied unmodified from the copy in GZDoom's ZWidget
(`gzdoom-nx/libraries/ZWidget/src/core/nanosvg/`).

hbmenu's Switch 2 build uses them to draw its icons from SVG
(`switch2/vector_assets.c`, `switch2/render.c`).
