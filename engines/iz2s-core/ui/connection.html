В SmileBASIC 4 выберите «Создание программы» (Make a Program). Настройте NS2IZA один раз. Если он уже сохранён, откройте «Запуск».

Проверка необязательна. При сохранении подтвердите диалог на Switch; существующий NS2IZM будет заменён только после вашего подтверждения.

Введите шесть чисел с экрана: количество символов и контрольную сумму каждой из трёх частей.

ЧастьСимволыСумма123

Подтвердите Save / Overwrite на Switch и дождитесь окончания сохранения.

Запуск из сохранённого NS2IZM. Доступ к SD запрашивается автоматически; после запуска IZ2S панель на ПК не нужна.
