# Установка и обновление IZ2S для Civilization VII

[English](INSTALLATION.md) · [Требования и установка панели](../README.ru.md)

Инструкция соответствует четырём шагам панели 0.34 и лаунчеру 0.34, ревизия `RUN34-0.34`. Нужны Switch 2 с прошивкой **23.0.1** и **картридж для Nintendo Switch 1 Civilization VII 1.0.0**. Первоначальная передача через LDN требует настоящего Linux, подходящего Wi-Fi адаптера и собственных ключей Switch 1.

## 1. SD-карта

Возьмите `iz2sciv-core-sd.zip` рядом с `install.sh` в распакованном Linux-комплекте или скачайте SD-пакет в панели. Перед заменой сохраните резервные копии имеющихся файлов на ПК. Распакуйте содержимое ZIP в корень карты: должно получиться `SD:/iz2s/...`, без дополнительной внешней папки.

**Если у вас старая версия IZ2S, обновите файлы на SD-карте.** Объедините каталоги и замените совпадающие файлы из нового пакета. Папку `Nintendo`, другие приложения, BIOS, игры, сохранения и настройки оставьте на месте. Лицензии из комплекта нужны вместе с распространяемыми компонентами. Безопасно извлеките карту и вставьте её в выключенную консоль.

В комплект входят согласованные файлы среды и лаунчера, IZ2S Cheese, IZPSX, Foldrift и NX2 BreRUN. Кэш GPU конкретной консоли в архив не включён. Не смешивайте старые ревизии R-Entry и Menu и не меняйте контрольные суммы для обхода ошибки проверки.

## 2. Подготовка ПК

В панели выберите собственный `prod.keys`, полученный со своей Switch 1. Ключи в сборку не входят. Завершите проверки зависимостей и разрешений; необходимую команду для сетевых прав Linux покажет панель.

Выберите Wi-Fi адаптер для LDN. Одного Ethernet недостаточно. На время передачи выбранный радиомодуль освобождается, затем панель восстанавливает его подключение. После восстановления ПК должен видеть консоль по локальной сети. WSL не подходит для первоначальной передачи.

## 3. Подключение и сохранение

1. Полностью перезагрузите консоль.
2. До запуска Civilization VII выберите **English** для интерфейса и **English (US)** для USB-клавиатуры. Пути в русском интерфейсе консоли:
   - Интерфейс: `HOME → Системные настройки → Система → Язык → English`.
   - Ввод: `HOME → Системные настройки → Контроллеры и аксессуары → USB-клавиатура → English (US)`.
3. **Если полностью повторяете процедуру или переходите с другого загрузчика:** очистите все сохранения Civilization VII выбранного профиля через `HOME → System Settings → Data Management → Delete Save Data → Civilization VII → Your profile`.
4. Создайте новое беспроводное лобби: `Civilization VII 1.0.0 → Multiplayer → Wireless → Create Game → Host Lobby`.
5. Подтвердите «Я перезагрузил консоль и открыл новое беспроводное лобби» и нажмите **«Подключить и установить сохранение»**.

Панель передаст первоначальный загрузчик, восстановит Wi-Fi ПК, проверит загрузчик консоли и автоматически установит `IZ2SCIV.Civ7Save`. До завершения оставьте экран **Awaiting payload** открытым. При успешном подключении вторую кнопку установки нажимать не нужно. Установщик записывает своё служебное сохранение через временный файл и подтверждает фиксацию файловой системы; другие обычные сохранения игры при этой операции остаются на месте.

Прогресс и действия восстановления находятся в **«Состоянии сеанса»**. Если автопоиск не сработал, откройте **«IP консоли: автопоиск или выбор адреса»** сразу под этим блоком. Найдите адреса, выберите и проверьте нужный либо введите IP с экрана консоли. Обнаруженный сетевой адрес ещё не означает подходящий загрузчик: перед передачей панель проверяет его. При необходимости вернитесь к автоопределению.

Если подключение прошло, а установка сохранения завершилась ошибкой, используйте предложенный повтор установки. Если не восстановилась сеть, нажмите **«Восстановить Wi-Fi ПК»** до новой передачи. После прерванной передачи LDN создайте новое лобби и подтвердите это перед повтором. Подробности доступны в журнале сеанса.

## 4. Запуск IZ2S

Выйдите в **HOME**, с помощью **X** закройте Civilization VII и снова откройте Civilization VII, затем выберите **Load Game**. **Консоль на этом этапе не перезагружайте.**

Дождитесь **IZ2S CORE IS RUNNING**. Вместо надписи может появиться чёрный экран; подождите около минуты и продолжайте по инструкции панели. Закройте Civilization VII обычным способом. Удерживая **R**, откройте игру для Switch 2. Если первая попытка только зарегистрировала параметры запуска игры, повторите запуск с R один раз.

При FAILED, недоступной файловой системе или зависании полностью перезагрузите консоль и повторите процедуру запуска. Если не получилось более семи раз, повторите полную установку. При постоянной ошибке `sd-verify` нужны файлы одной сборки на SD и соответствующее установленное сохранение; отключать проверки целостности нельзя.

Для следующих запусков используйте вкладку **«Запуск»**. Оттуда можно открыть инструкции или пройти полную процедуру сначала. При активной связи с консолью статус и инструменты подключения показаны первыми, ручная инструкция раскрывается отдельно.

## PC Link и FTP

Для PC Link откройте **«Запуск → Настроить PC Link»**, введите локальный IPv4-адрес консоли и нажмите **«Запустить PC Link»**. Скачайте `pc-link.cfg` и сохраните его по пути `SD:/iz2s/pc-link.cfg`. Снова откройте IZ2S и нажмите **R + L3**. ПК и консоль должны быть в одной локальной сети. Если PC Link работает в другой панели IZ2S, сначала приостановите его там.

После включения FTP на консоли нажмите **«Подключить FTP»** в панели. Для файлов откройте **Super File Bros**, для приложений - **«Библиотеку приложений»**. Обычно FTP использует порт 1425, но ориентируйтесь на адрес и порт на экране консоли. После снятия с дока подключите консоль к Wi-Fi, через который доступен ПК.

## Обновление

Новую панель установите в новую папку. Перед записью SD сохраните заменяемые файлы на ПК, скопируйте только подготовленный комплект и сверьте запись перед безопасным извлечением. Если ресурс открыт лаунчером, используйте картридер или отдельное FTP-приложение: собственный FTP IZ2S не может безопасно заменить заблокированный ROMFS.

При изменении совместимости среды и сохранения обновите SD и повторите полную процедуру панели. Сохранение содержит манифест выбранных файлов среды. Изменение только документации или расположения блоков панели само по себе не требует обновления сохранения на консоли.

Сохраняйте рабочий кэш шейдеров консоли. В этой ревизии исправлена его замена, а проверка соответствия шейдерам и драйверу сохранена. Первый запуск, которому нужен новый кэш, всё ещё может быть дольше повторного. Проверка на ПК не измеряет полное время от удержания R до появления меню.
